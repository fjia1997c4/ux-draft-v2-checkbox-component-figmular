Component Variants
Example
Role
Enabled is how checkboxes will appear to a user when no action has been taken yet but users are able to select it.
Disabled is how the checkbox will appear when no action can be taken by the user.
Error is how the checkbox will appear to signal when an incorrect action was taken by the user.
Example
Role
False - this how a checkbox will appear when it is NOT selected.
True- this is how a checkbox will appear when it IS selected.
Example
Role
Default - communicates that a component or element is interactive.
Hover - communicates to a user that the button is ready to be clicked- when mouse is hovering over an interactive element.
Pressed - communicates to a user that an action will happen once they’ve finished clicking an interactive element.
Focus - communicates to the user that the checkbox is ready to receive input via the keyboard or assistive technologies.
